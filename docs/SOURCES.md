# Verified sources

Checked on November 4, 2026, using the official Seeed, Espressif, SFMTA, 511, Google and upstream library documentation.

| Topic | Source and implementation decision |
|---|---|
| Device family and E1001 specifications | [Seeed reTerminal E Series](https://wiki.seeedstudio.com/reterminal_e10xx_main_page/): ESP32-S3, monochrome 800 × 480, 32 MB flash and 8 MB PSRAM. Connected device flash and chip identity were also queried with esptool. |
| Exact panel and pins | [Seeed Arduino display cookbook](https://wiki.seeedstudio.com/reterminal_e10xx_with_arduino/): GxEPD2_750_GDEY075T7; SCK7, MOSI9, CS10, DC11, RESET12, BUSY13; dedicated HSPI, 2 MHz. |
| Buttons, battery, LED and SD | [Seeed peripheral cookbook](https://wiki.seeedstudio.com/reterminal_e10xx_with_arduino_peripherals/): LED6 active-low; KEY0=3 (green right button), KEY1=4 (middle), KEY2=5 (left); battery ADC1 and enable21, 2× voltage divider; SD enable16 and CS14. |
| Sleep constraints | [Espressif ESP32-S3 sleep documentation](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/system/sleep_modes.html): radios do not maintain connections during manual light sleep or deep sleep. |
| Stop and direction | [SFMTA N Judah route](https://www.sfmta.com/routes/n-judah) lists **13911** under East to Caltrain via Downtown; [specific stop](https://www.sfmta.com/stops/carl-st-cole-st-13911). Stop 13909 is the other direction. |
| Transit APIs and rate limit | [511 Transit Data](https://511.org/open-data/transit): default 60 requests per 3600 seconds per token; Trip Updates bulk feed supplies both directions in one request; no separate alert polling. |
| JSON response shapes | [511 Transit specification v1.35](https://511.org/media/6657/show): StopMonitoring examples on pages 86–87; ServiceAlerts JSON on pages 93–94. Timestamp, monitored/scheduled, cancellation, notice, period, and affected-route fields inform the parser fixtures. |
| Google private feed | [Google Calendar subscription instructions](https://support.google.com/calendar/answer/37648): the secret iCal address provides subscription access without publishing the calendar. |
| Recurrence library | [libical](https://github.com/libical/libical), version 3.0.20, commit `57ce34025066935f356fd539e6deb7a7a9952618`. C core and generated headers are vendored, with a portable single-threaded configuration. [Recurrence API](https://libical.github.io/libical/) supports RFC calendar expansion; application code resolves overrides and bounds work. |
| Panel implementation | [GxEPD2 upstream](https://github.com/ZinggJM/GxEPD2), pinned 1.6.4. The exact driver's header reports partial-update capability; the application uses full refresh until hardware ghosting/cadence measurements justify changing it. |
| Typography | The user's [edited Figma frame 13:731](https://www.figma.com/design/i1Zm1OzpfqhNiXNap5Ijfr?node-id=13-731) supplied the current layout and spacing. The user's subsequent instruction restores [Inter](https://github.com/google/fonts/tree/main/ofl/inter) text and retains [Geist Mono](https://github.com/google/fonts/tree/main/ofl/geistmono) numerals at Light (300), keeping the revised sizes and tracking. Fonts and SIL Open Font Licenses are bundled. |
| Battery artwork | Original 17 × 12 SVG exported by Figma for frame 13:731, downloaded to `assets/battery.svg` and rasterized without resizing. The numerical voltage is measured; the fixed icon is decorative. |

The original Google OAuth path and BLE gateway were considered, then replaced by the requested private subscription URL and standalone Wi-Fi runtime. No APK analysis or reverse engineering was used.

Google TLS commissioning on November 13 found the served chain `*.google.com → WE2 → GTS Root R4 → GlobalSign Root CA`. The existing Mozilla bundle trusts GTS Root R4, but its retired GlobalSign signer is absent. The pinned Arduino compact verifier cannot terminate at that earlier trusted root; [Espressif issue 8626](https://github.com/espressif/arduino-esp32/issues/8626) documents this class of cross-signing failure. Google connections now use the existing GTS roots as full PEM certificates for ordinary mbedTLS path selection. No new roots or insecure fallback were added.

November 13, 2026 update: [SFMTA outbound stop 13909](https://www.sfmta.com/stops/carl-st-cole-st-13909) and authenticated 511 route-stop metadata confirm the outbound platform (neither platform has a parent station). The [official GTFS-Realtime schema](https://github.com/google/transit/blob/master/gtfs-realtime/proto/gtfs-realtime.proto) and [reference](https://gtfs.org/documentation/realtime/reference/) define the bounded wire reader. `tests/fixtures/511-n-tripupdates.pb` preserves the original header and N-route entities from a public 511 feed with header timestamp 1794609112; no API key is included. Figma frame [43:455](https://www.figma.com/design/i1Zm1OzpfqhNiXNap5Ijfr?node-id=43-455) supplies the two-direction paired layout and original next-train arrow.
